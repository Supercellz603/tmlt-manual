# บทที่ 2 	การเข้าใช้งานในระบบ


## 2.1 วิธีเข้าสู่ระบบ TMLT Mapping
ในการเข้าสู่ระบบ TMLT Mapping ผู้ใช้งานสามารถเข้าใช้งานได้ 2 ช่องทาง:

- ผ่านทางหน้าเว็บไซต์ **สำนักพัฒนามาตรฐานระบบข้อมูลสุขภาพไทย**
- ผ่านทางลิงก์โดยตรง: **[https://this.or.th/service/tmlt/](https://this.or.th/service/tmlt/)**

info Single Sign-On (SSO)
เมื่อเลือกเข้าสู่ระบบ TMLT Mapping จะพบกับหน้าล็อคอินผ่านระบบการเข้าถึงบริการอิเล็กทรอนิกส์แบบรวมศูนย์ **(Single Sign-On)** ดังภาพต่อไปนี้


![หน้าlogin](/img/login.png)
โดยเมื่อลงชื่อเข้าใช้งานสำเร็จ จะเข้าสู่หน้าสร้าง mapping ใหม่ เป็นหน้าแรก ดังภาพแสดงดังต่อไปนี้

![Mapping ใหม่](/img/MappingNew.png)
** หากเจ้าหน้าที่หน่วยบริการไม่มีชื่อผู้ใช้งาน ให้ลงทะเบียนเพื่อเข้าใช้งาน
