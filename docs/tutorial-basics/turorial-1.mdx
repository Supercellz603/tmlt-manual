## ขั้นตอนการดำเนินการ (Workflow)

1. **การนำเข้าข้อมูล**

   1.1. เริ่มต้นจากการจับคู่ Lab Code ของหน่วยบริการกับรหัส TMLT โดยสามารถทำได้ 2 วิธีคือ การพิมพ์ข้อมูล **(Key in)** หรือการนำเข้าข้อมูล **(Import Data)**

2. **กระบวนการจับคู่รหัส (TMLT Mapping)**

   2.1. ระบบจะทำการตรวจสอบเพื่อจับคู่กับรหัสมาตรฐาน (TMLT Mapping)

   2.2. **กรณีที่ 1: Mapping ได้** ข้อมูลจะเข้าสู่ขั้นตอนของ TMLT และส่งต่อไปยังกระบวนการตรวจสอบ Mapping

   &nbsp;&nbsp;&nbsp;&nbsp;2.2.1. **✅ ถ้าผ่าน:** จัดส่งข้อมูลให้ สกส. (เฉพาะหน่วยบริการที่ส่งข้อมูลเบิกจ่ายกับ สกส.) เพื่อบันทึกลงฐานข้อมูลและตรวจสอบผ่าน Lab catalog ต่อไป

   &nbsp;&nbsp;&nbsp;&nbsp;2.2.2. **❌ ถ้าไม่ผ่าน:** ต้องทำการ<span style={{color: '#FF874F'}}>**แก้ไข**</span>ข้อมูลแล้ววนกลับไปที่ขั้นตอน TMLT Mapping อีกครั้ง

   2.3. **กรณีที่ 2: Mapping ไม่ได้ (NO TMLT)** ข้อมูลจะถูกส่งต่อไปยัง สมสท. เพื่อดำเนินการ

   &nbsp;&nbsp;&nbsp;&nbsp;2.3.1. สมสท. จะตรวจสอบข้อมูลว่าเข้าเงื่อนไขใด

   &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;2.3.1.1. **กรณีมี TMLT อยู่แล้ว:** จะแจ้งให้ขอข้อมูลเพิ่ม และวนกลับไปแก้ไขเพื่อทำการ Mapping ใหม่

   &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;2.3.1.2. **กรณีไม่มี TMLT ในระบบ:** สมสท. จะดำเนินการ<span style={{color: '#FF874F'}}>**ออกรหัส TMLT ใหม่**</span>ให้กับรายการนั้นๆ ก่อนจะวนกลับไปที่ขั้นตอน TMLT Mapping เพื่อให้สามารถจับคู่รหัสได้สำเร็จ
