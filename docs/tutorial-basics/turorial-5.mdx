# บทที่ 5 โครงสร้าง Release ไฟล์ TMLT

## Release File คืออะไร

Release File คือ ชุดไฟล์มาตรฐานของ TMLT ที่จัดส่งให้โรงพยาบาลตามรอบวันที่ออกข้อมูล

:::info ตัวอย่างชื่อไฟล์
**TMLTRFYYYYMMDD** โดย YYYYMMDD คือวันที่ของรอบ release เช่น **TMLTRF20260514**
:::

ภายในชุดไฟล์จะประกอบด้วย:

| ส่วนประกอบ | รายละเอียด |
|---|---|
| 📁 **Snapshot** | โฟลเดอร์หลักส่วนที่ 1 |
| 📁 **Full** | โฟลเดอร์หลักส่วนที่ 2 |
| 📄 **TMLT-Manual.pdf** | ไฟล์คู่มือการใช้งาน |
| 📄 **Changelog.xlsx** | ไฟล์บันทึกการเปลี่ยนแปลง |

## 2. TMLT Snapshot ประกอบด้วย

### 2.1 TMLT_Core_Snapshot_YYYYMMDD

ไฟล์นี้เป็นไฟล์หลักที่รวมข้อมูลสำคัญของรหัส TMLT ไว้ในไฟล์เดียว เหมาะสำหรับโรงพยาบาลใช้เปิดดู ค้นหารหัส TMLT เพื่อนำไป Mapping ในไฟล์มีรายละเอียด ดังนี้

| Field | คำอธิบาย |
|---|---|
| TMLTID | รหัส TMLT |
| Status | สถานะของรายการ เช่น Active หรือ Inactive |
| Type | ประเภทของรายการ เช่น Item หรือ Panel |
| FSN | Fully Specified Name หรือชื่อเต็มมาตรฐานที่ระบุรายละเอียดครบทุกองค์ประกอบ |
| Synonym | ชื่อเรียกอื่นของรายการตรวจ |
| Component | สิ่งที่ตรวจวัด เช่น Glucose, Creatinine, Hemoglobin |
| Scale | ลักษณะการรายงานผล เช่น เชิงปริมาณ เชิงคุณภาพ หรือ ordinal |
| Unit | หน่วยของผลตรวจ |
| Specimen | ชนิดสิ่งส่งตรวจ เช่น Serum, Plasma, Urine, Whole blood |
| Method | วิธีการตรวจ หากมีการระบุ |
| LOINC | รหัสอ้างอิง LOINC |
| CGDCode | รหัส CGD |
| CGDName | ชื่อรายการตามข้อมูลอ้างอิงของกรมบัญชีกลาง |
| CGDPrice | ราคาหรือข้อมูลตามประกาศกรมบัญชีกลาง |
| Created | วันที่สร้างรายการ |
| LastUpdated | วันที่ปรับปรุงข้อมูลล่าสุด |

## 4. Changelog_YYYYMMDD.xlsx

ไฟล์นี้ใช้สำหรับแสดงรายการที่มีการเปลี่ยนแปลงในรอบ Release นั้นๆ เพื่อให้โรงพยาบาลสามารถตรวจสอบได้ว่า TMLT ใดมีการแก้ไขข้อมูล เช่น เปลี่ยนประเภทจาก Item เป็น Panel, แก้ไขชื่อ, แก้ไข Component, Specimen, Method หรือข้อมูลอ้างอิงอื่นๆ หรือมี TMLT ใหม่รหัสใดบ้าง ในไฟล์มีรายละเอียด ดังนี้

| Field | คำอธิบาย |
|---|---|
| RecType | ประเภทของ record เช่น **BEFORE** คือข้อมูลเดิมก่อนแก้ไข และ **CHANGED** คือข้อมูลหลังแก้ไข |
| TMLTID | รหัส TMLT ที่มีการเปลี่ยนแปลง |
| Status | สถานะของรายการ เช่น ACTIVE หรือ INACTIVE |
| LongCommonName | ชื่อที่อ่านง่ายหรือชื่อใช้งานทั่วไปของรายการตรวจ |
| Type | ประเภทของรายการ เช่น ITEM หรือ PANEL |
| FSN | Fully Specified Name หรือชื่อเต็มมาตรฐาน |
| Synonym | ชื่อเรียกอื่นของรายการตรวจ |
| Component | สิ่งที่ตรวจวัด |
| Scale | ลักษณะการรายงานผล |
| Unit | หน่วยของผลตรวจ |
| Specimen | ชนิดสิ่งส่งตรวจ |
| Method | วิธีการตรวจ |
| LOINC | รหัสอ้างอิง LOINC |
| CGDCode | รหัส CGD |
| Version | Version หรือรอบข้อมูลที่เกี่ยวข้องกับการเปลี่ยนแปลง |
