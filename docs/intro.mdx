# คำนำ

## เกี่ยวกับระบบ TMLT Mapping

สำนักพัฒนามาตรฐานระบบข้อมูลสุขภาพไทย (สมสท.) มุ่งเน้นการจัดทำและพัฒนาบัญชีรายการและรหัสมาตรฐานการตรวจทางห้องปฏิบัติการทางการแพทย์ของประเทศไทย หรือ Thai Medical Laboratory Terminology (TMLT) โดยได้พัฒนาโปรแกรม TMLT Mapping ซึ่งเป็นระบบออนไลน์ที่เชื่อมต่อกับฐานข้อมูลของสมสท. โดยตรง เพื่ออำนวยความสะดวกให้โรงพยาบาลสามารถนำเข้าข้อมูลรายการตรวจทางห้องปฏิบัติการ และดำเนินการจับคู่รหัสระหว่างรหัสโรงพยาบาล และรหัส TMLT ได้อย่างสะดวกและเป็นมาตรฐานมากยิ่งขึ้น เพื่อช่วยสนับสนุนการจัดทำ Lab Catalog เพื่อใช้เป็นบัญชีอ้างอิงสำหรับการเบิกจ่ายค่ารักษาพยาบาลในแต่ละกองทุนตามข้อกำหนดที่เกี่ยวข้อง
โดยรหัส TMLT ได้มีการพัฒนามาอย่างต่อเนื่อง เพื่อให้มีความน่าเชื่อถือ และมีมาตรฐานมากขึ้น โดยได้อ้างอิงแนวทางการพัฒนารหัส ตามมาตรฐานการตรวจทางห้องปฏิบัติการทางการแพทย์สากล คือ รหัส LOINC หรือ Logical Observation Identifiers Names and Codes
นอกจากนี้ โปรแกรม TMLT Mapping ยังช่วยลดระยะเวลาในการจับคู่รหัสและการจัดทำ Lab Catalog ของโรงพยาบาล อีกทั้งยังสามารถสืบค้นข้อมูลรายการตรวจทางห้องปฏิบัติการของแต่ละโรงพยาบาล รวมถึงข้อมูลมาตรฐาน TMLT ภายในระบบได้อย่างมีประสิทธิภาพ ส่งผลให้การบริหารจัดการข้อมูลทางห้องปฏิบัติการมีความถูกต้อง เป็นระบบ และสอดคล้องกับมาตรฐานระดับประเทศมากยิ่งขึ้น
