# บทนำ

## เกี่ยวกับระบบ TMLT Mapping

สำนักพัฒนามาตรฐานระบบข้อมูลสุขภาพไทย (สมสท.) มุ่งเน้นจัดทำและพัฒนาบัญชีรายการและรหัสมาตรฐานการตรวจทางห้องปฏิบัติการทางการแพทย์ไทย (TMLT) ได้จัดทำโปรแกรม TMLT Mapping โดยเป็นโปรแกรมระบบออนไลน์ที่มีฐานข้อมูล (Database) ติดต่อกับสมสท. โดยตรง เพื่ออำนวยความสะดวกให้ผู้ใช้ในการจับคู่รหัส (Mapping) ระหว่างรหัสโรงพยาบาล รหัสกรมบัญชีกลาง และรหัส TMLT ทั้งนี้ เพื่อให้โรงพยาบาลนำข้อมูลเข้ามาเพื่อทำการจับคู่รหัสได้สะดวกและเพื่อเพิ่มความแม่นยำในการจับคู่รหัส โดยอ้างอิงการจับคู่รหัสตามการพัฒนามาตรฐานรหัสการตรวจทางห้องปฏิบัติการทางการแพทย์ (Logical Observation Identifiers Names and Codes : LOINC) และการจัดทำ Lab Catalog เพื่อใช้เป็นบัญชีอ้างอิง สำหรับการเบิกจ่ายค่ารักษาพยาบาลในแต่ละกองทุนฯ ที่มีการกำหนดไว้ ซึ่งช่วยให้โรงพยาบาลลดระยะเวลาการจับคู่รหัสและการจัดทำ Lab Catalog ได้มากขึ้น รวมทั้งสามารถค้นหาข้อมูลรายการตรวจฯ ของแต่ละโรงพยาบาล และฐานข้อมูล TMLT ในโปรแกรม TMLT Mapping ได้
