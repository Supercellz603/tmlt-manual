บทที่ 5 โครงสร้าง Release ไฟล์ TMLT

Release File คืออะไร​

Release File คือ ชุดไฟล์มาตรฐานของ TMLT ที่จัดส่งให้โรงพยาบาลตามรอบวันที่ออกข้อมูล

ตัวอย่างชื่อไฟล์

TMLTRFYYYYMMDD โดย YYYYMMDD คือวันที่ของรอบ release เช่น TMLTRF20260514

ภายในชุดไฟล์จะประกอบด้วย:

ส่วนประกอบรายละเอียด
📁 Snapshotโฟลเดอร์หลักส่วนที่ 1
📁 Fullโฟลเดอร์หลักส่วนที่ 2
📄 TMLT-Manual.pdfไฟล์คู่มือการใช้งาน
📄 Changelog.xlsxไฟล์บันทึกการเปลี่ยนแปลง

2. TMLT Snapshot ประกอบด้วย​

2.1 TMLT_Core_Snapshot_YYYYMMDD​

ไฟล์นี้เป็นไฟล์หลักที่รวมข้อมูลสำคัญของรหัส TMLT ไว้ในไฟล์เดียว เหมาะสำหรับโรงพยาบาลใช้เปิดดู ค้นหารหัส TMLT เพื่อนำไป Mapping ในไฟล์มีรายละเอียด ดังนี้

Fieldคำอธิบาย
TMLTIDรหัส TMLT
Statusสถานะของรายการ เช่น Active หรือ Inactive
Typeประเภทของรายการ เช่น Item หรือ Panel
FSNFully Specified Name หรือชื่อเต็มมาตรฐานที่ระบุรายละเอียดครบทุกองค์ประกอบ
Synonymชื่อเรียกอื่นของรายการตรวจ
Componentสิ่งที่ตรวจวัด เช่น Glucose, Creatinine, Hemoglobin
Scaleลักษณะการรายงานผล เช่น เชิงปริมาณ เชิงคุณภาพ หรือ ordinal
Unitหน่วยของผลตรวจ
Specimenชนิดสิ่งส่งตรวจ เช่น Serum, Plasma, Urine, Whole blood
Methodวิธีการตรวจ หากมีการระบุ
LOINCรหัสอ้างอิง LOINC
CGDCodeรหัส CGD
CGDNameชื่อรายการตามข้อมูลอ้างอิงของกรมบัญชีกลาง
CGDPriceราคาหรือข้อมูลตามประกาศกรมบัญชีกลาง
Createdวันที่สร้างรายการ
LastUpdatedวันที่ปรับปรุงข้อมูลล่าสุด

2.2 TMLT_Concept_Snapshot_YYYYMMDD.xlsx​

ไฟล์นี้ใช้แสดงรายการ concept ของ TMLT ว่าแต่ละรหัสเป็นประเภทใด เช่น Item, Panel หรือ Part ในไฟล์มีรายละเอียด ดังนี้

Fieldคำอธิบาย
TMLTIDรหัส TMLT
Typeประเภทของ concept เช่น Item, Panel หรือ Part
Statusสถานะของ concept เช่น Active หรือ Inactive
Createdวันที่สร้าง concept
LastUpdatedวันที่ปรับปรุงข้อมูลล่าสุด

2.3 TMLT_Description_Snapshot_YYYYMMDD.xlsx​

ไฟล์นี้ใช้เก็บชื่อหรือคำอธิบายของ TMLT แต่ละรายการ เช่น ชื่อเต็มตามมาตรฐาน ชื่อเรียกอื่น และชื่อที่ใช้ทั่วไป ในไฟล์มีรายละเอียด ดังนี้

Fieldคำอธิบาย
DescriptionIdรหัสของ description
TMLTIDรหัส TMLT ที่ description นี้อ้างถึง
Termคำหรือชื่อของรายการตรวจ
Typeประเภทของชื่อ เช่น FSN, SYN, Long Common Name
Statusสถานะของ description เช่น Active หรือ Inactive
Createdวันที่สร้างข้อมูล
LastUpdatedวันที่ปรับปรุงข้อมูลล่าสุด

2.4 TMLT_PartLink_Snapshot_YYYYMMDD.xlsx​

ไฟล์นี้ใช้บอกว่า Item หนึ่งรายการประกอบด้วย Part อะไรบ้าง เช่น component, specimen, scale, unit หรือ method ในไฟล์มีรายละเอียด ดังนี้

Fieldคำอธิบาย
RelationIDรหัสความสัมพันธ์ระหว่าง item กับ part
TMLTIDรหัส TMLT ของ item
PartIDรหัส TMLT Part ที่เป็นส่วนประกอบของ item
Typeประเภทของ part เช่น Component, Specimen, Scale, Unit, Method
Statusสถานะ เช่น Active หรือ Inactive
Createdวันที่สร้างข้อมูล
LastUpdatedวันที่ปรับปรุงข้อมูลล่าสุด

2.5 TMLT_PanelMember_Snapshot_YYYYMMDD.xlsx​

ไฟล์นี้ใช้บอกว่า Panel หนึ่งรายการประกอบด้วย Item อะไรบ้าง ในไฟล์มีรายละเอียด ดังนี้

Fieldคำอธิบาย
MemberIDรหัสสมาชิกของ panel
ParentTMLTIDรหัส TMLT ของ Panel
ChildTMLTIDรหัส TMLT ที่อยู่ภายใต้ Panel นั้น
Statusสถานะของสมาชิกใน panel เช่น Active หรือ Inactive
Createdวันที่สร้างข้อมูล
LastUpdatedวันที่ปรับปรุงข้อมูลล่าสุด

2.6 TMLT_Extra_Snapshot_YYYYMMDD.xlsx​

ไฟล์นี้ใช้เก็บข้อมูลอ้างอิงเพิ่มเติมของ TMLT เช่น LOINC, CGDCode, CGDTerm, CGDPrice หรือ SNOMED ในไฟล์มีรายละเอียด ดังนี้

Fieldคำอธิบาย
ExtraIDรหัสข้อมูลเพิ่มเติม
TMLTIDรหัส TMLT ที่ข้อมูลเพิ่มเติมนี้อ้างถึง

Valueค่าของข้อมูลตามประเภทนั้น
Statusสถานะของข้อมูล เช่น Active หรือ Inactive

4. Changelog_YYYYMMDD.xlsx​

ไฟล์นี้ใช้สำหรับแสดงรายการที่มีการเปลี่ยนแปลงในรอบ Release นั้นๆ เพื่อให้โรงพยาบาลสามารถตรวจสอบได้ว่า TMLT ใดมีการแก้ไขข้อมูล เช่น เปลี่ยนประเภทจาก Item เป็น Panel, แก้ไขชื่อ, แก้ไข Component, Specimen, Method หรือข้อมูลอ้างอิงอื่นๆ หรือมี TMLT ใหม่รหัสใดบ้าง ในไฟล์มีรายละเอียด ดังนี้

Fieldคำอธิบาย
RecTypeประเภทของ record เช่น BEFORE คือข้อมูลเดิมก่อนแก้ไข และ CHANGED คือข้อมูลหลังแก้ไข
TMLTIDรหัส TMLT ที่มีการเปลี่ยนแปลง
Statusสถานะของรายการ เช่น ACTIVE หรือ INACTIVE
LongCommonNameชื่อที่อ่านง่ายหรือชื่อใช้งานทั่วไปของรายการตรวจ
Typeประเภทของรายการ เช่น ITEM หรือ PANEL
FSNFully Specified Name หรือชื่อเต็มมาตรฐาน
Synonymชื่อเรียกอื่นของรายการตรวจ
Componentสิ่งที่ตรวจวัด
Scaleลักษณะการรายงานผล
Unitหน่วยของผลตรวจ
Specimenชนิดสิ่งส่งตรวจ
Methodวิธีการตรวจ
LOINCรหัสอ้างอิง LOINC
CGDCodeรหัส CGD
VersionVersion หรือรอบข้อมูลที่เกี่ยวข้องกับการเปลี่ยนแปลง
