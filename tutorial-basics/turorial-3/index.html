บทที่ 3 วิธีการจัดทำ TMLT Mapping

ในบทนี้ประกอบด้วยขั้นตอนการจัดทำ TMLT Mapping โดยมีวิธีการดำเนินการดังนี้

3.1 การสร้าง Mapping​

เจ้าหน้าที่หน่วยบริการสามารถสร้าง TMLT Mapping เพื่อเชื่อมโยง รหัสการตรวจทางห้องปฏิบัติการของหน่วยบริการ (Lab code) เข้ากับ รหัสมาตรฐานการตรวจทางห้องปฏิบัติการทางการแพทย์ไทย (รหัส TMLT) โดยสามารถสร้างได้ 2 วิธี ดังนี้

3.1.1 สร้างโดยการนำเข้าไฟล์ Excel​

  1. เลือกข้อความ "เทมเพลตสำหรับ import" สำหรับการดาวน์โหลดเทมเพลตที่ใช้ในการกรอก mapping และนำเข้าสู่ระบบ โดยจะต้องกรอกข้อมูลในช่องที่บังคับให้กรอกครบทุกช่อง จึงจะสามารถนำเข้าไฟล์ได้ โดยข้อมูลที่จำเป็นต้องกรอกคือ

    1.1. ช่องกรอกรหัสการตรวจแล็บของหน่วยบริการ (LAB_CODE)

    1.2. ช่องเลือกสถานที่ตรวจ โดยมีให้เลือกคือ ตรวจเองและส่งตรวจภายนอก (LOCATION)

    1.3. ประเภทการตรวจทางห้องปฏิบัติการฯของหน่วยบริการ (LAB_TYPE) โดยมีให้เลือกคือ การตรวจที่เป็นรายการ (ITEM) หรือ การตรวจเป็นชุด (PANEL)

    1.4. TMLT Code: รหัส TMLT ที่ต้องการ Mapping

    1.5. Local name: ชื่อการตรวจของหน่วยบริการ (LAB_NAME) เช่น FBS

    1.6. Component: การตรวจนี้เป็นการตรวจเพื่อหาอะไร หรือต้องการตรวจวัดอะไร

    1.7. Specimen: ประเภทของสิ่งส่งตรวจ เช่น Serum or Plasma, Sputum หรือ Urine เป็นต้น (จำเป็นต้องกรอก หากไม่มีให้ระบุ N/A)

    1.8. Scale: ชนิดของการวัด หรือรูปแบบการรายงานผล เช่น Quantitative (จำเป็นต้องกรอก หากไม่มีให้ระบุ N/A)

    1.9. Unit: หน่วยของการวัด เช่น mg/dL, g/dL หรือ mol/L เป็นต้น (จำเป็นต้องกรอก หากไม่มีให้ระบุ N/A)

  2. เลือกปุ่ม "นำเข้าข้อมูลจากไฟล์" เลือกไฟล์ที่ผู้ใช้งานได้ดาวน์โหลดและทำการเพิ่ม TMLT mapping แล้ว เมื่อนำเข้าสู่ระบบ จะแสดงสถานะตอนนำเข้า มีทั้งหมด 3 แบบ ได้แก่

    สถานะความหมาย
    ✅ น่าจะถูกต้องรหัสการตรวจฯ (Lab code) มีรายละเอียดต่างๆ ตรงกับรหัส TMLT ที่เลือก
    ⚠️ ควรทบทวนรายละเอียดบางส่วนหรือทั้งหมดไม่ตรงกับรหัส TMLT แต่ระบบยังอนุญาตให้นำเข้าได้
    ❌ มีข้อผิดพลาดระบบไม่สามารถนำเข้าไฟล์ได้ ต้องแก้ไขก่อน
คำเตือน

ระบบไม่อนุญาตให้นำเข้าไฟล์นั้นๆ ได้ จนกว่าจะมีการแก้ไขข้อผิดพลาดตามที่ระบบแจ้งจนครบถ้วน

สาเหตุที่พบบ่อย:

  • ไฟล์ Excel มีหัวตารางไม่ตรงกับเทมเพลต
  • มีรหัสการตรวจแล็บซ้ำกันในไฟล์
  • รายการที่นำเข้ารหัสการตรวจแล็บแล้ว และรายการดังกล่าวอยู่สถานะ "รอตรวจ"

โดยเมื่อระบบตรวจพบข้อมูลที่มีสถานะควรทบทวนและมีข้อผิดพลาด ระบบจะทำการแสดงเหตุผลที่ทำให้เกิดสถานะนั้นๆ พร้อมมีปุ่มดาวน์โหลดไฟล์ที่จะระบุข้อควรทบทวนหรือข้อผิดพลาด ในระดับแถวตาราง เพื่อความสะดวกของผู้ใช้งานในการแก้ไข

ภาพแสดงตัวอย่างการแจ้งเตือนข้อผิดพลาดจากระบบ TMLT ภาพตัวอย่างไฟล์ที่แสดง Error กับ Waring ที่ดาวน์โหลด

3.1.2 สร้าง Mapping ผ่านฟอร์มในระบบ​

  1. เลือกปุ่ม "สร้างใหม่" เพื่อเข้าสู่หน้าฟอร์มการสร้าง TMLT mapping โดยรายละเอียดแต่ละช่อง สามารถดูได้ที่สัญลักษณ์ ⓘ โดยจะแสดงคำอธิบายของแต่ละช่อง
จุดสำคัญ

หากต้องการทราบรายละเอียดของแต่ละช่อง ให้กดที่สัญลักษณ์ ⓘ หน้าช่องนั้นๆ

  1. หมายเลข 2 คือ ช่องกรอกรหัสการตรวจแล็บของหน่วยบริการ หรือ Local code (จำเป็นต้องกรอก) หากมี Local Code ดังกล่าวอยู่แล้วในระบบ จะมีการแจ้งเตือนให้ทราบ "Local code XXXX ถูกใช้ในระบบแล้ว"

    2.1 Lab Code นั้นมีสถานะผ่านแล้ว (Approved) ระบบจะแสดงข้อความแจ้งเตือน “พบรหัส Lab Code ซ้ำ Lab Code: XXXXXX มี Mapping ที่ Approved แล้วอยู่ในระบบ ต้องการสร้าง Mapping นี้อีกครั้งหรือไม่? แต่ถ้าหากยืนยันว่าต้องการทำรายการนี้ใหม่ ให้กด “ยืนยัน”

    2.2 Lab Code นั้นมีสถานะรอตรวจ ระบบจะแสดงข้อความแจ้งเตือน “Local code: 100011 ถูกใช้ในระบบแล้ว” จะไม่สามารถแก้ไข จะไม่สามารถแก้ไขได้ จนกว่า Admin จะตรวจสอบ

  1. หมายเลข 3 คือ ช่องเลือกสถานที่ตรวจ โดยมีให้เลือกคือ ตรวจเองและส่งตรวจภายนอก (จำเป็นต้องกรอก)

  2. ช่องกรอกรายละเอียดของ mapping ฝั่งรหัสการตรวจทางห้องปฏิบัติการฯของหน่วยบริการ (Lab code) โดยสามารถเลือกจาก Dropdown หรือสามารถพิมพ์เองได้ ประกอบด้วย

    ข้อช่องรายละเอียด
    4.1ประเภทการตรวจที่เป็นรายการ (ITEM) หรือ การตรวจเป็นชุด (PANEL) (จำเป็นต้องกรอก)
    4.2TMLT Codeรหัส TMLT ที่ต้องการ Mapping (จำเป็นต้องกรอก)
    4.3Local nameชื่อการตรวจของหน่วยบริการ เช่น Fasting blood glucose (จำเป็นต้องกรอก)
    4.4Componentการตรวจนี้เป็นการตรวจเพื่อหาอะไร หรือต้องการตรวจวัดอะไร (จำเป็นต้องกรอก)
    4.5Specimenประเภทของสิ่งส่งตรวจ เช่น Serum or Plasma, Urine (จำเป็นต้องกรอก หากไม่มีให้ระบุ N/A)
    4.6Scaleรูปแบบการรายงานผล เช่น Quantitative (จำเป็นต้องกรอก หากไม่มีให้ระบุ N/A)
    4.7Unitหน่วยของการวัด เช่น mg/dL, g/dL (จำเป็นต้องกรอก หากไม่มีให้ระบุ N/A)
    4.8Methodวิธีการตรวจ เช่น Immunoassay, NAA with probe detection

  3. หมายเลข 5 คือ ช่องค้นหาและเลือกข้อมูลขึ้นมาเปรียบเทียบกับข้อมูลในข้อ 4 โดยสามารถเลือกได้สองแบบ ได้แก่

    • อ้างอิงตามรหัส TMLT สามารถค้นหาได้จาก TMLT code, TMLT name, component, specimen, scale, unit, method, LOINC code และ CGD code
    • อ้างอิงตาม mapping ของหน่วยบริการอื่น สามารถค้นหาได้จาก รหัสหรือชื่อของหน่วยบริการ, TMLT code, TMLT name, component, specimen, scale, unit, method, LOINC code และ CGD code

    โดยเมื่อทำการเลือกแท็บของประเภทข้อมูลที่ต้องการอ้างอิง และทำการกรอกค่าลงในช่องค้นหา ระบบจะแสดงดังภาพต่อไปนี้

  4. หมายเลข 6 คือ ช่องแสดงข้อมูลที่จะทำการแสดงข้อมูลจากการกดรายการอ้างอิงที่ต้องการจากข้อที่ 5 โดยเมื่อกดรายการแล้ว ระบบจะแสดงดังภาพต่อไปนี้

  5. หมายเลข 7 คือ ปุ่มสำหรับทำการเลือกข้อมูลอ้างอิงจากข้อ 6 มาแทนค่าในช่องข้อมูลของข้อ 5 โดยหลังจากกดแล้วปุ่มสำหรับย้ายข้อมูลจะไม่สามารถกดได้อีก จนกว่าค่าทั้งสองฝั่งจะไม่เท่ากัน แต่ยังสามารถแก้ไข รายละเอียด Mapping ได้ ดังภาพตัวอย่างที่แสดงดังต่อไปนี้

  6. หมายเลข 8 คือ กล่องแสดงสถานะการเปรียบเทียบระหว่าง mapping ระหว่างข้อ 4 และ ข้อ 6 โดยหากยังไม่เลือกข้อมูลมาอ้างอิง กล่องจะแสดงสถานะ "กำลังพิจารณา" แต่หากเลือกแล้วระบบจะแสดงสถานะ "น่าจะถูกต้อง" หรือ "ควรทบทวน" ขึ้นอยู่กับความถูกต้องของข้อมูล

  7. หมายเลข 9 คือ ปุ่ม "ยกเลิก" เพื่อยกเลิกการสร้าง หากกดยกเลิกข้อมูลจะไม่ถูกบันทึกไว้ และ ปุ่ม "ยืนยัน" เพื่อยืนยันการสร้าง mapping

  8. หากกรอกข้อมูลช่องที่จำเป็นครบถ้วนจะสามารถ "บันทึก" ได้ แต่หากกรอกไม่ครบ ระบบจะไม่ให้บันทึก และแสดงกรอบสีแดงในช่องที่ยังไม่ได้ระบุรายละเอียด ดังภาพ

3.2 วิธีแก้ไข Mapping ที่ยังไม่ได้ส่งตรวจ​

  1. เลือกปุ่ม "รายละเอียด" สำหรับ mapping ที่ต้องการแก้ไข

  2. ระบบจะแสดงส่วนรายละเอียดของ mapping พร้อมไอคอนแก้ไข mapping หมายเลข 2 ทางด้านขวาบนของส่วนแสดงรายละเอียด ของ Mapping และประวัติการแก้ไข โดยเมื่อกดไอคอน ระบบจะเข้าสู่หน้าแก้ไข mapping

  1. หน้าแสดงฟอร์มการแก้ไข mapping โดยระบบจะดึงข้อมูลรายละเอียดของรหัส TMLT ที่ mapping นั้นๆ อ้างอิงมาแสดงในส่วนของ TMLT Mapping โดยอัตโนมัติเพื่อความสะดวกในการเทียบข้อมูล โดยหากเป็นรายการ mapping ที่ยังไม่ได้ส่งตรวจสอบ จะสามารถแก้ไขได้ทุกช่องข้อมูล
tip
  1. เมื่อแก้ไขเรียบร้อย ให้กดปุ่ม "ยืนยัน" หากต้องการบันทึกข้อมูล และกดปุ่ม "ยกเลิก" หากไม่ต้องการบันทึกข้อมูล

3.3 วิธีส่ง mapping เพื่อให้เจ้าหน้าที่ สมสท. ตรวจสอบ​

  1. ทำการเลือกกล่องตัวเลือกสำหรับรายการ mapping ที่ต้องการส่งให้เจ้าหน้าที่ สมสท. ตรวจสอบ โดยสามารถเลือกทั้งแบบทีละรายการหรือเลือกทั้งหมด

  2. เลือกปุ่ม “ส่งตรวจ” เพื่อทำการส่งรายการ mapping ที่เลือกให้เจ้าหน้าที่ สมสท. ตรวจสอบ

  1. เมื่อกดปุ่ม "ส่งตรวจ" ระบบจะแสดงหน้าต่างยืนยันการส่งตรวจ โดยส่วนที่แสดงคือ

    • จำนวนรายการ mapping ทั้งหมดที่ส่งตรวจ
    • จำนวนรายการ mapping ที่มีสถานะ "ควรทบทวน"

  2. ปุ่มทางเลือกสำหรับเจ้าหน้าที่หน่วยบริการ เพื่อยกเลิก หรือ ยืนยันการส่งตรวจ โดยหากเลือกยืนยันการส่งตรวจ mapping ทั้งหมดที่เลือกจะเปลี่ยนสถานะเป็น "รอตรวจสอบ"

  3. หากรายการ mapping ที่บางรายการมีสถานะเป็น Approved แล้ว จะมีข้อความแสดงให้ทางหน่วยบริการรับทราบเพื่อป้องกันการส่งซ้ำโดยไม่ตั้งใจ แต่ทั้งนี้หากหน่วยบริการยืนยันที่จะส่งรายการดังกล่าวซ้ำ สามารถกดปุ่ม "ยืนยัน" เพื่อส่งซ้ำได้

  4. ปุ่มทางเลือกสำหรับเจ้าหน้าที่หน่วยบริการ เพื่อยกเลิก หรือ ยืนยันการส่งตรวจ โดยหากเลือกยืนยันการส่งตรวจ mapping ทั้งหมดที่เลือกจะเปลี่ยนสถานะเป็น “รอตรวจสอบ”

5.หากรายการ TMLT รายการ mapping ที่บางรายการมีสถานะเป็น Approved แล้ว จะมีข้อความแสดงให้ทางหน่วยบริการรับทราบเพื่อป้องกันการส่งซ้ำโดยไม่ตั้งใจ แต่ทั้งนี้หากหน่วยบริการยืนยันที่จะส่งรายการดังกล่าวซ้ำ สามารถกดปุ่ม “ยืนยัน” เพื่อส่งซ้ำได้

หมายเหตุ

กรณีที่ส่งรายการที่มีสถานะ Approved มาให้ทาง สมสท. ตรวจสอบซ้ำ หากรายการดังกล่าวมีการจัดทำ Lab Catalogue แล้ว จะต้องจัดทำ Lab Catalogue ใหม่อีกครั้ง

3.4 วิธีการลบ Mapping​

การลบ Mapping จะสามารถทำได้เฉพาะกรณีที่รายการดังกล่าวเป็น “Mapping ใหม่ หรือ Mapping รอแก้ไข” ซึ่งเป็นรายการที่รอส่งมาให้ทาง สมสท. ตรวจสอบเท่านั้น หากมีสถานะ “Mapping รอตรวจสอบ หรือ “ Mapping เสร็จสิ้น” จะไม่สามารถลบได้ รายละเอียด ดังภาพ

ภาพแสดงรายการที่สามารถลบได้

3.5 วิธีตรวจสอบ mapping ที่อยู่ในสถานะรอตรวจสอบ​

  1. เลือกแท็บ "Mapping รอตรวจสอบ" เพื่อเข้าสู่หน้าแสดงรายการ mapping ทั้งหมดของหน่วยบริการ ที่อยู่ในสถานะ "รอตรวจสอบ"

  2. ส่วนแสดงรายการ mapping ทั้งหมดที่มีสถานะ "รอตรวจสอบ"

  3. ปุ่ม "รายละเอียด" เพื่อแสดงรายละเอียดข้อมูลทั้งหมดของ mapping นั้นๆ โดยเมื่อเลือกปุ่ม ระบบจะแสดงข้อมูลดังภาพถัดไป

  4. ส่วนแสดงแถบสถานะของ mapping

    4.1. "รอตรวจสอบ" คือ รอ สมสท. ตรวจสอบ

    4.2. "ควรทบทวน" คือ ความถูกต้องของ mapping นั้นๆ

    4.3. "Inactive" รายการนี้รอ สมสท. ตรวจสอบ ระบบจะแสดงเป็น "Inactive" เมื่อทาง สมสท. ตรวจสอบเรียบร้อยและ mapping ดังกล่าวมีสถานะ "ผ่าน" ระบบจะเปลี่ยนจาก "Inactive" เป็น "Active" อัตโนมัติ

  5. ส่วนแสดงรายละเอียดทั้งหมดของ mapping

  6. ส่วนแสดงประวัติการแก้ไขทั้งหมดของ mapping

หมายเหตุ

mapping ที่อยู่ในสถานะ "รอตรวจสอบ" จะไม่สามารถแก้ไขได้

3.6 วิธีแก้ไข mapping ที่ไม่ผ่านการอนุมัติจากเจ้าหน้าที่ สมสท.​

  1. เลือกแท็บ "Mapping รอแก้ไข" เพื่อเข้าสู่หน้ารายการ mapping ทั้งหมดของหน่วยบริการที่ไม่ผ่านการตรวจสอบจากเจ้าหน้าที่ สมสท.

  2. ส่วนแสดงรายการ mapping ทั้งหมดที่มีสถานะ "รอแก้ไข"

  3. ปุ่ม "แก้ไข" รายการที่ต้องการแก้ไข โดยจะเข้าสู่หน้าฟอร์มแก้ไขข้อมูลของ mapping นั้นๆ เมื่อทำการกดปุ่ม ระบบจะแสดงดังภาพ

  4. ส่วนแสดงเหตุผลที่ mapping ไม่ผ่านการอนุมัติจากเจ้าหน้าที่ สมสท.

  5. ช่องกรอกรายละเอียดของ mapping ฝั่งรหัสการตรวจทางห้องปฏิบัติการฯของหน่วยบริการ (Lab code) โดยระบบจะทำการแสดงกรอบสีเหลืองในช่องข้อมูลที่ไม่ตรงกับรหัส TMLT

  6. ช่องค้นหาและเลือกข้อมูลขึ้นมาเปรียบเทียบกับข้อมูลในข้อ 5

  7. ช่องแสดงข้อมูลอ้างอิงโดยระบบจะแสดงข้อมูลของรหัส TMLT ที่ mapping อ้างถึงโดยอัตโนมัติ และสามารถปรับเปลี่ยนได้จากการกดรายการอ้างอิงที่ต้องการจากข้อที่ 6

  8. ปุ่มสำหรับทำการเลือกข้อมูลอ้างอิงจากข้อ 7 มาแทนค่าในช่องข้อมูลของข้อ 5

  9. กล่องแสดงสถานะการเปรียบเทียบระหว่าง mapping ระหว่างข้อ 5 และ ข้อ 7 โดยหากยังไม่เลือกข้อมูลมาอ้างอิง กล่องจะแสดงสถานะ "กำลังพิจารณา" แต่หากเลือกแล้วระบบจะแสดงสถานะ "น่าจะถูกต้อง" หรือ "ควรทบทวน" ขึ้นอยู่กับความถูกต้องของข้อมูล

  10. ปุ่ม "ยกเลิก" เพื่อยกเลิกการแก้ไข หากกดยกเลิกข้อมูลจะไม่ถูกบันทึกไว้ และ ปุ่ม "ส่งตรวจอีกครั้ง" เพื่อส่งมาให้ สมสท. ตรวจสอบอีกครั้ง

  11. ที่หน้า "Mapping ใหม่" เลือกรายการที่แก้ไข และส่ง mapping ใหม่เพื่อให้เจ้าหน้าที่ สมสท. ตรวจสอบอีกรอบ

หมายเหตุ

สามารถอ่านรายละเอียดการทำงานของแต่ละส่วนได้ในหัวข้อ 2.1.1.2

3.7 วิธีตรวจสอบ mapping ที่อนุมัติแล้วและนำข้อมูลออกไปจัดทำ lab catalog​

  1. เลือกแท็บ "Mapping เสร็จสิ้น" เพื่อเข้าสู่หน้ารายการ mapping ทั้งหมดของหน่วยบริการที่ผ่านการอนุมัติจากเจ้าหน้าที่ สมสท.

  2. ส่วนแสดงรายการ mapping ทั้งหมดที่มีสถานะ "เสร็จสิ้น"

  3. ปุ่ม "รายละเอียด" เพื่อดูรายละเอียดข้อมูลของ mapping นั้นๆ

หมายเหตุ

mapping ที่มีสถานะ "เสร็จสิ้น" ไม่สามารถแก้ไขได้

  1. กล่องตัวเลือกของ mapping เพื่อนำไปใช้ในการนำออกเป็น Lab Catalog

  2. สถานะการดาวน์โหลด

    สถานะความหมาย
    ดาวน์โหลดแล้วรายการดังกล่าวเคยมีการดาวน์โหลดแล้ว แต่ยังสามารถดาวน์โหลดซ้ำได้
    ยังไม่ได้ดาวน์โหลดรายการดังกล่าวยังไม่เคยมีการดาวน์โหลด
    หมายเหตุ

    เนื่องจากรายการ mapping ได้มีการย้ายข้อมูลจากระบบเก่ามาระบบใหม่ (Migration) ทำให้รายการที่อยู่ในระบบเดิมจะมีสถานะเป็น "ยังไม่ได้ดาวน์โหลด"

  3. สถานะส่ง สกส. คือ สถานะที่ระบบ TMLT ส่งรายการ mapping ที่มีสถานะผ่านแล้วไปยัง สกส. โดยจะเป็นการส่งอัตโนมัติในเวลา 15:00 น. ของทุกวัน หากรายการดังกล่าวถูกส่งไปแล้วจะมีเครื่องหมาย ✅

แนะนำ

ขั้นตอนจัดทำ Lab Catalog แนะนำให้หน่วยบริการจัดทำหลังจากสถานะการส่ง สกส. มีเครื่องหมาย ✅ เท่านั้น

  1. ปุ่ม "ส่งออกข้อมูล Mapping" หากรายการที่ดาวน์โหลดยังไม่มีเครื่องหมาย ✅ ระบบจะแสดงข้อความแจ้งเตือน

    "Local Code ต่อไปนี้ยังไม่ได้ส่ง สกส. ท่านต้องการส่งออกข้อมูลต่อหรือไม่"

    เมื่อกดปุ่ม "ยืนยัน" ระบบจะสร้างไฟล์ Excel ให้

  2. เมื่อทำการส่งออกข้อมูล Mapping แล้ว จะได้รับไฟล์สำหรับจัดทำ Lab Catalogue ตามโครงสร้างของ สกส. โดยข้อมูลที่นำออกจากระบบ TMLT Mapping จะประกอบด้วย HCODE, LCCode, BillGroup, CsCode, TMLT, LOINC, Panel, Name และ ReimbPrice

    ในส่วนของข้อมูลอื่นๆ ที่ต้องกรอกเพิ่มเติม ได้แก่

    ข้อฟิลด์รายละเอียด
    8.1Flagประเภทการรายงานผล
    8.2ChargeCatประเภทการเรียกเก็บ
    8.3UnitPriceราคาเรียกเก็บต่อหน่วย
    8.4BenefitPlanสิทธิประโยชน์ที่กำหนดราคาเบิกได้
    8.5UpdateFlagสถานะการปรับปรุงข้อมูล
    8.6UPDateBegวันที่และเวลา ราคาเรียกเก็บ (UnitPrice) เริ่มใช้
    8.7UPDateEndวันที่และเวลา ราคาเรียกเก็บ (UnitPrice) ยุติการใช้
    8.8RPDateBegวันที่และเวลา ราคาเบิก (ReimbPrice) เริ่มใช้
    8.9RPDateEndวันที่และเวลา ราคาเบิก (ReimbPrice) ยุติการใช้
    8.10DateUpdวันที่และเวลาที่สถานพยาบาลส่งให้ปรับปรุงรายการในระบบ
หมายเหตุ

ข้อมูลในตารางข้างต้น (8.1 - 8.10) ต้องกรอกเพิ่มเติมเอง เนื่องจาก สมสท. ดูแลเฉพาะส่วน TMLT Mapping เท่านั้น

ภาพแสดงรายละเอียดไฟล์ที่ได้รับจากระบบ TMLT

ข้อมูลข้อ 8.1 - 8.10 หรืออื่นๆตามโครงสร้างการจัดทำ Lab catalogue ที่ทาง สกส.กำหนด โดยทางหน่วยบริการต้องระบุเพิ่มในไฟล์ excel เอง เนื่องจาก สมสท. จะดูแลเฉพาะในส่วน TMLT Mapping เท่านั้น
