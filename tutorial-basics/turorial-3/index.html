บทที่ 3 วิธีการจัดทำ TMLT Mapping

ขั้นตอนการจัดทำ TMLT Mapping มีวิธีการดำเนินการ ดังนี้

3.1 การสร้าง Mapping​

เจ้าหน้าที่หน่วยบริการสามารถสร้าง TMLT mapping ระหว่างรหัสการตรวจทางห้องปฏิบัติการฯของหน่วยบริการ (Lab code) เข้ากับรหัสมาตรฐานการตรวจทางห้องปฏิบัติการทางการแพทย์ไทย หรือ รหัส TMLT โดยสามารถสร้างได้ 2 วิธี ดังนี้

3.1.1 สร้างโดยการนำเข้าไฟล์ Excel​

  1. เลือกข้อความ "เทมเพลตสำหรับ import" สำหรับการดาวน์โหลดเทมเพลตที่ใช้ในการกรอกข้อมูล โดยจะมีทั้งหมด 10 คอลัมน์ โดยจะต้องกรอกข้อมูลในช่องที่บังคับให้กรอกครบทุกช่อง จึงจะสามารถนำเข้าข้อมูลจากไฟล์ได้ โดยข้อมูลที่จำเป็นต้องกรอกคือ
ข้อฟิลด์รายละเอียด
1.1LAB_CODEกรอกรหัสการตรวจแล็บของหน่วยบริการ
1.2LOCATIONระบุสถานที่ตรวจ หากตรวจเองให้ระบุ 1 และหากส่งตรวจภายนอกให้ระบุ 2
1.3LAB_TYPEประเภทการตรวจทางห้องปฏิบัติการของหน่วยบริการ หากเป็นการตรวจแบบรายการ ITEM ให้ระบุ 1 และหากเป็นการตรวจแบบชุด PANEL ให้ระบุ 2
1.4TMLTรหัส TMLT ที่ต้องการจับคู่ Mapping
1.5LAB_NAMEชื่อการตรวจของหน่วยบริการ เช่น FBS
1.6COMPONENTรายการตรวจนี้เป็นการตรวจเพื่อหาอะไร หรือต้องการตรวจวัดอะไร เช่น Creatinine
1.7SPECIMENประเภทของสิ่งส่งตรวจ เช่น Serum or Plasma, Sputum หรือ Urine เป็นต้น
1.8SCALEรูปแบบการวัด ได้แก่
- Quantitative หมายถึง การรายงานผลที่เป็นปริมาณ เช่น mg/L เป็นต้น
- Ordinal หมายถึง การรายงานผลที่สามารถเรียงลำดับได้ เช่น +, -, positive, negative, 1+, 2+ เป็นต้น
- Semi-Quantitative หมายถึง ผลตรวจที่รายงานเป็นระดับหรือช่วงปริมาณ
- Nominal หมายถึง การรายงานผลที่เป็นชื่อ bacteria, virus หรือลักษณะของปัสสาวะ สีของน้ำไขสันหลัง เช่น yellow, clear, bloody เป็นต้น
1.9UNITหน่วยของการวัด เช่น mg/dL, g/dL หรือ mol/L เป็นต้น หากไม่มีให้ระบุ N/A
หมายเหตุ

ช่อง METHOD (วิธีการตรวจ) เป็นข้อมูลที่ไม่บังคับกรอก แต่แนะนำให้กรอกหากทราบ เพื่อให้รายละเอียดของรายการตรวจครบถ้วนและชัดเจนยิ่งขึ้น

  1. เลือกปุ่ม "นำเข้าข้อมูลจากไฟล์" เลือกไฟล์ที่ผู้ใช้งานได้ดาวน์โหลดและทำการเพิ่ม TMLT mapping แล้ว เมื่อนำเข้าสู่ระบบ จะแสดงสถานะตอนนำเข้า มีทั้งหมด 3 แบบ ได้แก่

    2.1. น่าจะถูกต้อง คือ รหัสการตรวจทางห้องปฏิบัติการฯของหน่วยบริการ (Lab code) มีรายละเอียดต่างๆตรงกับรหัส TMLT ที่เลือก

    2.2. ควรทบทวน คือ รหัสการตรวจทางห้องปฏิบัติการฯของหน่วยบริการ (Lab code) มีรายละเอียดบางส่วนหรือทั้งหมด ไม่ตรงกับรหัส TMLT ที่เลือก แต่ระบบยังคงอนุญาตให้นำเข้าข้อมูลนั้นๆเข้าสู่ระบบ แต่จะมีสถานะ ควรทบทวน

    2.3. สามารถกดปุ่มดูรายละเอียดแต่ละรายการได้ หากรายการไหนเป็นควรทบทวน ระบบจะแสดงช่องที่ควรทบทวนเป็นพื้นหลังสีเหลือง และจะแสดงค่าของรหัส TMLT ที่ Mapping มาเทียบให้ ดังภาพ

    2.4. มีข้อผิดพลาด คือ สถานะที่ระบบแสดงเมื่อเกิดข้อผิดพลาดที่ส่งผลให้ระบบไม่สามารถนำเข้าไฟล์เทมเพลตได้ เช่น

    • ไฟล์ Excel มีหัวตารางไม่ตรงกับเทมเพลต
    • มีรหัสการตรวจแล็บซ้ำกันในไฟล์
    • ระบุรายละเอียดที่จำเป็นไม่ครบ
    • รายการที่นำเข้ารหัสการตรวจแล็บแล้ว และรายการดังกล่าวอยู่สถานะ "รอตรวจ" เป็นต้น

    2.5. เมื่อระบบตรวจพบข้อมูลที่มีสถานะควรทบทวนและมีข้อผิดพลาด ระบบจะทำการแสดงเหตุผลที่ทำให้เกิดสถานะนั้นๆ พร้อมมีปุ่มดาวน์โหลดไฟล์ที่จะระบุข้อผิดพลาด (error) หรือ ข้อควรทบทวน (Warning) ในระดับแถวว่าต้องแก้ไขอะไรบ้าง ซึ่งในไฟล์จะมีรายละเอียด ดังนี้

พบข้อผิดพลาด (error)

ระบบจะแสดงข้อความที่ช่อง error จำเป็นต้องแก้ไขให้ถูกต้องเท่านั้นจึงจะสามารถนำเข้าไฟล์ใหม่ได้

พบข้อควรทบทวน (warning)

พบข้อควรทบทวน (warning) ระบบจะแสดงข้อความที่ช่อง waring ให้ตรวจสอบว่าจะต้องแก้ไขอะไร เช่น Specimen ระบุเป็น Clotted blood แต่รหัส TMLT ที่ Mapping เป็น Serum or plasma ระบบก็จะแจ้งเตือนเนื่องจากไม่ตรงกับ TMLT หากเป็นข้อความ waring ไม่จำเป็นต้องแก้ไข ก็สามารถนำเข้าไฟล์ใหม่ได้ แต่ทั้งนี้แนะนำแก้ไขให้ถูกต้อง

3.1.2 สร้าง Mapping ผ่านฟอร์มในระบบ​

  1. เลือกปุ่ม "สร้างใหม่" เพื่อเข้าสู่หน้าฟอร์มการสร้าง TMLT mapping โดยรายละเอียดจะแสดงในภาพถัดไป โดยรายละเอียดแต่ละช่อง สามารถดูได้ที่สัญลักษณ์ ⓘ โดยจะแสดงคำอธิบายของแต่ละช่อง
  1. เมื่อเข้าสู่หน้าสร้างใหม่ระบบจะแสดงขั้นตอนการทำ Mapping เบื้องต้น โดยสามารถกดปุ่มปิดวิธีใช้งานได้

  1. ให้กรอกข้อมูลที่จำเป็น ดังนี้

    3.1. ช่องหมายเลข 2 ระบุ Lab Code หรือ รหัสการตรวจแล็บของหน่วยบริการ หากในระบบมี Lab Code ดังกล่าวอยู่แล้ว จะมีการแจ้งเตือน ดังนี้

    • Lab Code นั้นมีสถานะผ่านแล้ว (Approved) ระบบจะแสดงข้อความแจ้งเตือน "พบรหัส Lab Code ซ้ำ Lab Code: XXXXXX มี Mapping ที่ Approved แล้วอยู่ในระบบ ต้องการสร้าง Mapping นี้อีกครั้งหรือไม่?" แต่ถ้าหากยืนยันว่าต้องการทำรายการนี้ใหม่ ให้กด "ยืนยัน" หากยืนยันข้อมูลใหม่จะไปทับข้อมูลเดิม
    • Lab Code นั้นมีสถานะรอตรวจ ระบบจะแสดงข้อความแจ้งเตือน "Lab code: XXXXXX ถูกใช้ในระบบแล้ว" จะไม่สามารถแก้ไขได้ จนกว่า Admin จะตรวจสอบ

    3.2. หมายเลข 3 คือ ช่องเลือกสถานที่ตรวจ โดยมีให้เลือกคือ ตรวจเองและส่งตรวจภายนอก

    3.3. หมายเลข 4 คือ กรอกรายละเอียดของหน่วยบริการโดยสามารถเลือกจาก Dropdown หรือสามารถพิมพ์เองได้ ประกอบด้วย

    • ประเภท หรือ Lab type: ประเภทการตรวจทางห้องปฏิบัติการฯของหน่วยบริการ โดยมีให้เลือกคือ การตรวจที่เป็นรายการ (ITEM) หรือ การตรวจเป็นชุด (PANEL)
    • TMLT Code: รหัส TMLT ที่ต้องการ Mapping โดย 1 Lab Code สามารถจับคู่กับ TMLT ได้ 1 TMLT เท่านั้น เมื่อกรอกรหัส TMLT ระบบจะแสดงรายละเอียดของ TMLT ที่ฝั่งขวามือให้อัตโนมัติ ดังภาพ
    • Lab Name: ชื่อการตรวจของหน่วยบริการ เช่น FBS
    • Component: การตรวจนี้เป็นการตรวจเพื่อหาอะไร หรือต้องการตรวจวัดอะไร
    • Specimen: ประเภทของสิ่งส่งตรวจ เช่น Serum or Plasma, Sputum หรือ Urine เป็นต้น (หากไม่มีให้ระบุ N/A)
    • Scale: รูปแบบของการวัด หรือรูปแบบการรายงานผล เช่น Quantitative (หากไม่มีให้ระบุ N/A)
    • Unit: หน่วยของการวัด เช่น mg/dL, g/dL หรือ mol/L เป็นต้น (หากไม่มีให้ระบุ N/A)
    หมายเหตุ

    ช่อง Method (วิธีการตรวจ) เป็นข้อมูลที่ไม่บังคับกรอก แต่แนะนำให้กรอกหากทราบ เพื่อให้รายละเอียดของรายการตรวจครบถ้วนและชัดเจนยิ่งขึ้น

    3.4. หมายเลข 5 คือ ช่องค้นหาและเลือกข้อมูลขึ้นมาเปรียบเทียบกับข้อมูลในข้อ 3.3 โดยสามารถเลือกได้ 2 แบบ ได้แก่

    • อ้างอิงตามรหัส TMLT โดยสามารถค้นหาได้จาก TMLT code, TMLT name, component, specimen, scale, unit, method, LOINC code และ CGD code
    • อ้างอิงตาม mapping ของหน่วยบริการอื่น สามารถค้นหาได้จาก รหัสหรือชื่อของหน่วยบริการ, TMLT code, TMLT name, component, specimen, scale, unit, method, LOINC code และ CGD code

    เมื่อทำการเลือกแท็บของประเภทข้อมูลที่ต้องการอ้างอิง และทำการกรอกค่าลงในช่องค้นหา ระบบจะนำข้อมูลไประบุในหมายเลข 6 ดังภาพ

    3.5. หมายเลข 7 คือ ปุ่มสำหรับคัดลอกข้อมูลอ้างอิงจากข้อ 3.4 มาแทนค่าในช่องข้อมูลรายการตรวจของหน่วยบริการสามารถกดคัดลอกทั้งหมด หรือคัดลอกเฉพาะบางช่อง

    3.6. หมายเลข 8 คือ กล่องแสดงสถานะผลการประเมิน Mapping เบื้องต้นโดยระบบ

    • ผลประเมินเบื้องต้นแสดง "รอกรอกข้อมูล" หากยังไม่ได้กรอกข้อมูลที่ในฝั่งรายการตรวจของหน่วยบริการ
    • ผลประเมินเบื้องต้นแสดง "น่าจะถูกต้อง" หากรายละเอียดข้อมูลรายการตรวจของหน่วยบริการ เหมือนกับรายละเอียดตาม TMLT
    • ผลประเมินแสดง "ควรทบทวน" หมายถึง รายละเอียดของรายการตรวจหน่วยบริการไม่สอดคล้องกับรายละเอียดตาม TMLT ที่ Mapping ไว้ อย่างไรก็ตาม ไม่ได้หมายความว่าข้อมูลของหน่วยบริการผิด แต่อาจเกิดจากคำหรือรายละเอียดบางส่วนยังไม่มีอยู่ในระบบ จึงควรตรวจสอบเพิ่มเติมตามบริบทการใช้งานจริง

    3.7. หมายเลข 9 คือ ปุ่ม "ยกเลิก" เพื่อยกเลิกการสร้าง หากกดยกเลิกข้อมูลจะไม่ถูกบันทึกไว้ และ ปุ่ม "ยืนยัน" เพื่อยืนยันการสร้าง mapping

    3.8. หากกรอกข้อมูลช่องที่จำเป็นครบถ้วนจะสามารถ "บันทึก" ได้ แต่หากกรอกไม่ครบ ระบบจะไม่ให้บันทึก และแสดงกรอบสีแดงในช่องที่ยังไม่ได้ระบุรายละเอียด ดังภาพ

3.2 วิธีแก้ไข Mapping ที่ยังไม่ได้ส่งตรวจ​

  1. เลือกปุ่มรายละเอียดสำหรับ mapping ที่ต้องการแก้ไข

  2. ระบบจะแสดงส่วนรายละเอียดของ mapping พร้อมไอคอนแก้ไข และประวัติการแก้ไข โดยเมื่อกดไอคอน ระบบจะเข้าสู่หน้าแก้ไข mapping

  3. หน้าแสดงฟอร์มการแก้ไข mapping โดยระบบจะดึงข้อมูลรายละเอียดของรหัส TMLT ที่ mapping มาแสดงในส่วนรายละเอียดตาม TMLT โดยอัตโนมัติเพื่อความสะดวกในการเทียบข้อมูล โดยหากเป็นรายการ mapping ที่ยังไม่ได้ส่งตรวจสอบ จะสามารถแก้ไขได้ทุกช่องข้อมูล

tip
  1. เมื่อแก้ไขเรียบร้อย ให้กดปุ่ม "ยืนยัน" หากต้องการบันทึกข้อมูล และกดปุ่ม "ยกเลิก" หากไม่ต้องการบันทึกข้อมูล

3.3 วิธีส่ง mapping เพื่อให้เจ้าหน้าที่ สมสท. ตรวจสอบ​

  1. ทำการเลือกกล่องตัวเลือกสำหรับรายการ mapping ที่ต้องการส่งให้เจ้าหน้าที่ สมสท. ตรวจสอบ โดยสามารถเลือกทั้งแบบทีละรายการหรือเลือกทั้งหมด

  2. เลือกปุ่ม "ส่งตรวจ" เพื่อทำการส่งรายการ mapping ที่เลือกให้เจ้าหน้าที่ สมสท. ตรวจสอบ

  3. เมื่อกดปุ่ม "ส่งตรวจ" ระบบจะแสดงหน้าต่างยืนยันการส่งตรวจ โดยส่วนที่แสดงคือจำนวนรายการ mapping ทั้งหมดที่ส่งตรวจและจำนวนรายการ mapping ที่มีสถานะ "ควรทบทวน"

  1. ปุ่มทางเลือกสำหรับเจ้าหน้าที่หน่วยบริการ เพื่อยกเลิก หรือ ยืนยันการส่งตรวจ โดยหากเลือกยืนยันการส่งตรวจ รายการ mapping จะเปลี่ยนสถานะเป็น "รอตรวจสอบ"
  1. หากรายการ TMLT รายการ mapping ที่บางรายการมีสถานะเป็น Approved (เสร็จสิ้น) แล้ว จะมีข้อความแสดงให้ทางหน่วยบริการรับทราบเพื่อป้องกันการส่งซ้ำโดยไม่ตั้งใจ แต่ทั้งนี้หากหน่วยบริการยืนยันที่จะส่งรายการดังกล่าวซ้ำ สามารถกดปุ่ม "ยืนยัน" เพื่อส่งซ้ำได้
หมายเหตุ

กรณีที่ส่งรายการที่มีสถานะ Approved มาให้ทาง สมสท. ตรวจสอบซ้ำ หากรายการดังกล่าวมีการจัดทำ Lab Catalogue แล้ว จะต้องจัดทำ Lab Catalogue ใหม่อีกครั้ง

3.4 วิธีการลบ Mapping​

การลบ Mapping จะสามารถทำได้เฉพาะกรณีที่รายการดังกล่าวเป็น "Mapping ใหม่ หรือ Mapping รอแก้ไข" ซึ่งเป็นรายการที่รอส่งมาให้ทาง สมสท. ตรวจสอบเท่านั้น หากมีสถานะ "Mapping รอตรวจสอบ" หรือ "Mapping เสร็จสิ้น" จะไม่สามารถลบได้ รายละเอียด ดังภาพ

3.5 วิธีตรวจสอบรายการ Mapping ที่อยู่ในสถานะรอตรวจสอบ​

  1. เลือกแท็บ "Mapping รอตรวจสอบ" เพื่อเข้าสู่หน้าแสดงรายการ Mapping ทั้งหมดของหน่วยบริการ ที่อยู่ในสถานะ "รอตรวจสอบ"

  2. ปุ่มรายละเอียด เพื่อแสดงรายละเอียดข้อมูลของ Mapping นั้น Mapping ที่อยู่ในสถานะรอตรวจสอบ จะไม่สามารถแก้ไขได้

3.6 วิธีแก้ไข mapping ที่ไม่ผ่านการอนุมัติจากเจ้าหน้าที่ สมสท.​

  1. เลือกแท็บ "Mapping รอแก้ไข" เพื่อเข้าสู่หน้ารายการ mapping ทั้งหมดของหน่วยบริการที่ไม่ผ่านการตรวจสอบจากเจ้าหน้าที่ สมสท.
  1. กดปุ่ม "แก้ไข" รายการที่ต้องการแก้ไข โดยจะเข้าสู่หน้าฟอร์มแก้ไขข้อมูลของ mapping นั้นๆ เมื่อทำการกดปุ่ม ระบบจะแสดงดังภาพ

  1. หมายเลข 1 แสดงเหตุผลที่ Mapping ไม่ผ่านการอนุมัติจากเจ้าหน้าที่ สมสท. ให้หน่วยบริการแก้ไขให้ถูกต้องตามคำแนะนำ หากมีข้อสงสัยเพิ่มเติม สามารถติดต่อสอบถามได้ที่ Line Open Chat หรือส่ง Email มาได้ที่ tmlt@this.or.th

  2. หมายเลข 2 แสดงรายละเอียดการตรวจของหน่วยบริการโดยระบบจะทำการแสดงสีกรอบเหลืองในช่องข้อมูลที่ไม่ตรงกับรหัส TMLT

  3. หมายเลข 3 แสดงข้อมูล TMLT ที่ Mapping ไว้

  4. หมายเลข 4 ปุ่มสำหรับคัดลอกรายละเอียดตาม TMLT

  5. หมายเลข 5 แสดงผลการประเมินความถูกต้องเบื้องต้นโดยระบบของ Mapping นั้นๆ

  6. หมายเลข 6 สำหรับการค้นหา TMLT หรือ Mapping ของสถานพยาบาลอื่น เพื่อนำมาเปรียบเทียบและใช้อ้างอิง

  7. หมายเลข 7 เพื่อยกเลิกการแก้ไข หากกดยกเลิกข้อมูลจะไม่ถูกบันทึกไว้ และ ปุ่ม "ส่งตรวจอีกครั้ง" เพื่อส่งมาให้ สมสท. ตรวจสอบอีกครั้ง

  8. รายการ TMLT ที่ส่งตรวจอีกครั้ง จะเปลี่ยนสถานะเป็น "Mapping รอตรวจสอบ"

3.7 วิธีตรวจสอบ Mapping ที่อนุมัติแล้วและนำข้อมูลออกไปจัดทำ Lab Catalogue​

โดยมีรายละเอียดดังนี้

  1. เลือกแท็บ "Mapping เสร็จสิ้น" เพื่อเข้าสู่หน้ารายการ mapping ทั้งหมดของหน่วยบริการที่ผ่านการอนุมัติจากเจ้าหน้าที่ สมสท. โดยแสดงรายการ mapping ทั้งหมดที่มีสถานะ "เสร็จสิ้น"

  2. ปุ่ม "รายละเอียด" เพื่อดูรายละเอียดข้อมูลของ mapping นั้นๆ โดยไม่สามารถแก้ไขได้สำหรับ mapping สถานะ "เสร็จสิ้น"

  3. กล่องตัวเลือกของ mapping เพื่อนำไปใช้ในการนำออกเป็น Lab Catalog

  4. สถานะการดาวน์โหลด

    • ดาวน์โหลดแล้ว คือ รายการดังกล่าวเคยมีการดาวน์โหลด Excel แล้ว แต่ยังสามารถดาวน์โหลดซ้ำได้
    • ยังไม่ได้ดาวน์โหลด คือ รายการดังกล่าวยังไม่เคยมีการดาวน์โหลด
    หมายเหตุ

    เนื่องจากรายการ mapping ได้มีการย้ายข้อมูลจากระบบเก่ามาระบบใหม่ (Migration) ทำให้รายการที่อยู่ในระบบเดิมจะมีสถานะเป็น "ยังไม่ได้ดาวน์โหลด"

  5. สถานะส่ง สกส. คือ สถานะที่ระบบ TMLT ส่งรายการ mapping ที่มีสถานะผ่านแล้วไปยัง สกส. โดยจะเป็นการส่งอัตโนมัติในเวลา 15:00 น. ของทุกวัน หากรายการดังกล่าวถูกส่งไปแล้วจะแสดงสถานะ "ส่งแล้ว"

หมายเหตุ

ขั้นตอนจัดทำ Lab Catalogue แนะนำให้หน่วยบริการจัดทำหลังจากสถานะการส่ง สกส. เป็นสถานะ "ส่งแล้ว"

  1. ปุ่ม "ดาวน์โหลด Excel" สำหรับดาวน์โหลดข้อมูลเพื่อนำไปจัดทำ Lab Catalogue สามารถเลือกทั้งหมด หรือทีละรายการได้

  2. หากรายการที่ต้องการดาวน์โหลดสถานะการส่ง สกส. ยังเป็น "ยังไม่ได้ส่ง" จะแสดงข้อความแจ้งเตือน

    "Local Code ต่อไปนี้ยังไม่ได้ส่ง สกส. ท่านต้องการส่งออกข้อมูลต่อหรือไม่"

    โดยจะมีรหัส Lab Code แสดงให้ทราบ เมื่อกดปุ่มยืนยันระบบจะสร้างไฟล์ Excel ให้

  1. เมื่อทำการส่งออกข้อมูล Mapping แล้ว จะได้รับไฟล์สำหรับจัดทำ Lab Catalogue ตามโครงสร้างของสำนักสารสนเทศบริการสุขภาพ (สกส.) โดยข้อมูลที่นำออกจากระบบ TMLT Mapping จะประกอบด้วย HCODE, LCCode, BillGroup, CsCode, TMLT, LOINC, Panel, Name และ ReimbPrice ในส่วนของข้อมูลอื่นๆ ดังนี้
